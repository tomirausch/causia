# Cómo contribuir

1. Leé `docs/estandares-de-ingenieria.md` y `docs/adr/`.
2. Trabajá en una rama por tarea y abrí un pull request hacia `main` usando la plantilla.
3. El CI tiene que estar en verde y el responsable técnico tiene que aprobar el PR.
4. No subas datos reales: el repositorio es público.

Para delegar trabajo a una IA, usá `docs/plantilla-de-tarea.md`.
